# Local prototype boundaries

- The organizer signed URL and Gemini key stay server-side in an ignored `.env`. The extraction helper preserves existing values and never prints the URL. Backend errors omit upstream response bodies and raw provider exceptions; input-validation errors omit submitted data.
- Only the preconfigured HTTPS organizer URL is fetched. The request can replace only `group_id`; all other signed query bytes are retained. Private/nonpublic DNS targets and redirects are rejected. Audio is played directly in the browser; there is no arbitrary-URL audio proxy. A production connector should additionally use a pinned organizer hostname and network egress policy to defend against DNS rebinding.
- All real DEV conversations and raw provider outputs are local SQLite data, ignored by Git. Do not upload the database, exported evaluations, recordings, or real transcripts to public hosting. Export is explicit and includes original evidence. The shipped fixture contains synthetic data only.
- External processing of voice transcripts is blocked by default. Enable the backend flag only after data-controller/organizer authorization. Importing or reading a call does not send it to Gemini. No recordings are downloaded or analyzed by this build.
- No login is required by the hackathon. The reviewer-mode switch is a demonstration control, not access enforcement. Bind to loopback; do not expose the local server as a production banking system. Add authentication, authorization, encryption at rest, retention and rate limiting for deployment.
- React renders transcript text as text, without `dangerouslySetInnerHTML`. Recording URL input accepts only HTTP(S); links use `rel=noreferrer`. Modal controls support keyboard focus containment and Escape. Fonts are bundled locally for offline navigation.
- The model receives the checklist and messages, not API secrets or recording links. Structural validation cannot prove semantic correctness or eliminate prompt injection. Inspect financial uncertainty flags and contentious judgments.
